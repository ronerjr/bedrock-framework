# Contributing to Bedrock Java 🦖

First of all, thank you for considering contributing to Bedrock Java! It's through the open-source community that educational frameworks evolve.

## What are we looking for?
Our main goal is **Education** and **Zero Dependencies**.
- Suggestions to refactor code making it more explicit and readable.
- Adoption of new Java 21+ patterns (Pattern Matching, Records).
- Extension of the Dependency Injection engine.
- Refinement of the Bedrock Playground (UI).

## What to Avoid (Please Do Not Submit)
- PRs adding external dependencies (e.g., Jackson, Lombok, Tomcat). Our value lies in being *pure Java*.
- Excessively complex code focused solely on extreme performance at the expense of readability.

## How to Contribute
1. Fork the repository.
2. Create your branch (`git checkout -b feature/my-feature`).
3. Run the build to ensure everything passes (`mvn clean install`).
4. Commit your changes (`git commit -m 'Add some cool feature'`).
5. Push to the branch (`git push origin feature/my-feature`).
6. Open a Pull Request.

Make yourself at home! 🦴
