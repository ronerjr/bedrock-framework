The foundation of
modern architecture

Learn to walk on the JVM before piloting spaceships like Spring and Quarkus. No magic, zero dependencies, pure Java 21.

⚡

Java 21 & Virtual Threads

Abandon reactive complexity. Bedrock uses the native HttpServer configured with Virtual Threads for ultra-high concurrency without OS blocking.

🪞

Reflection without Magic

Our custom IoC engine resolves dependencies recursively using Constructor Injection, enforcing immutability and preventing circular dependencies.

📦

Zero Dependencies

No external libraries at runtime! We built a native JSON serializer via Reflection with first-class support for Java Records and Collections.

Getting Started

        
Run Bedrock Java locally.

        
        

            

                
1

                

                    
Clone or download the project

                    
Make sure you have JDK 21+ installed on your machine.

                

            

            

                
2

                

                    
Import the project

                    
The project uses Maven. Just import the pom.xml file.

                

            

            

                
3

                

                    
Execute the application

                    
Run the com.bedrock.example.Application class from your IDE.

                

            

            

                
4

                

                    
Access the Bedrock Playground

                    
Open your browser at http://localhost:8080/bedrock/ui to test the API and see all active routes graphically.
